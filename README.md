# rutube-kodi
Unofficial Rutube video addon for Kodi

Плагин для просмотра видео на сайте Rutube на Коди 20+.
Тестируется на Ubuntu 26.04 и Kodi 21.3.
Плагин использует только публичные веб-эндпоинты Rutube.
Лицензия MIT.

В настройках «Выбор качества видео» добавлены два значения: «Не выше 720p» и «Не выше 480p». Старые значения не изменились (0, 1, 2), по умолчанию по-прежнему «Всегда максимальное (1080p)». (Для внешнего плеера включите флажок «Выбирать качество в плагине и отдавать плееру прямую ссылку»)

В контекстном меню любого видео (долгое нажатие или правая кнопка) добавлен пункт «Скачать видео». (При первой загрузке аддон спросит папку и запомнит её. Изменить папку можно в настройках аддона. Загрузка идёт в фоне, с полосой прогресса: можно листать список и смотреть другое видео. Остановить её можно пунктом «Остановить текущую загрузку» в главном меню (он виден только пока идёт загрузка). При ошибке, остановке или выходе из Kodi недокачанный файл удаляется.

В контекстном меню видео добавлен пункт "похожие видео". Настоящих рекомендаций «похожие» от Rutube я гарантировать не могу: их адрес нигде не документирован. Список вариантов строится по названию, описанию и хештегам

Добавлено чтение комментариев. Читаются до 3 страниц. Если комментариев больше, внизу будет пометка «показаны первые N».

Добавлен родительский фильтр. Видео без рейтинга не затрагиваются. Фильтр действует на поиск, каналы, плейлисты и витрину.

Сделал настройку для скрытия шортсов (короткие вертикальные видео).

Экспорт в медиатеку: не всё подряд, а по выбору. В контекстном меню папки сериала, плейлиста канала и подборки вида «сериал PREMIER» появился пункт «Добавить в медиатеку Kodi». Экспортируется только то, что выбрали. Работает и для сериалов, которые аддон сам собрал из заголовков, и для плейлистов и лент Rutube: серии берутся тем же способом, что при открытии папки. В несколько сезонов серии раскладываются по папкам Season 01, Season 02 (номер сезона берётся из названия плейлиста, если в названии серий его нет).Для каждой серии создаётся .strm со ссылкой на воспроизведение через плагин и, по настройке, .nfo с названием, описанием, обложкой и длительностью. Повторный запуск добавляет только новые серии. Серии без номера в названии (например, «Анонс сезона») пропускаются. Один раз добавьте папку экспорта как источник: Видео → Файлы → Добавить видео… → Обзор → папка экспорта . Если папка ещё не добавлена, аддон при первом экспорте покажет эту подсказку. После этого сериал будет с отметками просмотренного и «Продолжить просмотр». Если папка уже источник, аддон сам запускает обновление медиатеки. (Настройка «Метаданные экспортированных сериалов»: по умолчанию данные Rutube (.nfo), либо только .strm, и тогда Kodi возьмёт описания и постеры у скрейпера TMDb. Для сериалов с нестандартными названиями, как у НТВ, надёжнее данные Rutube)

Добавил историю просмотра: новый пункт главного меню. Хранит до 100 видео, новые сверху, без дублей. Повторный просмотр поднимает запись наверх. В контекстном меню «Убрать из истории», сверху пункт «Очистить историю просмотра» с подтверждением.
Добавил историю поиска: меню «Поиск» показывает «Новый поиск» и до 30 последних запросов, то же для «Поиск каналов». Пока истории нет, поиск открывает клавиатуру сразу, как раньше. Страницы «Показать ещё» и служебные поиски («похожие» и т.п.) в историю не попадают.
Хранение: файл history.json в профиле плагина, только на устройстве, никуда не отправляется. Отключается флажком «Сохранять историю просмотра и поиска».
